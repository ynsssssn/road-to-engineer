## 🚀 Core Projects Highlights

### 1. 허수 지표 개선을 통한 재무적 경영 목표 달성 기여
- **Background:** 2026년 상반기 '구독자 수 2배(2.5만 -> 5만)'라는 도전적 KPI 수립.
- **Problem:** 기존 결제 지연/미납 유저(약 1천 명)가 구독자 수에 포함되어, KPI 달성 시에도 실제 영업이익(재무 실적)에 구멍이 생길 수 있는 심각한 리스크 발견.
- **Action:** 프로덕트 책임자에게 즉각 보고 및 미납 30일 초과 유저 강제 해지 프로세스 제안. 미납 사유 및 특징을 세그먼트화하여 전달.
- **Impact:** 단순히 보여주기식 KPI(Vanity Metric)가 아닌, 실제 기업의 수익성과 일치하는 북극성 지표로 재정립. 현재 미납금 정산 및 자동 해지 프로세스 개발 진행 중.

### 2. 현장 서비스 품질 개선을 위한 VIP 유저 클러스터링 및 파이프라인 구축
- **Background:** 상위 1000명 VIP 유저의 VoC 증가 원인이 '입고 과정에서의 세탁 사고'임을 현장 지원을 통해 발견.
- **Problem:** 현장 입고 근무자가 해당 고객의 VIP 여부나 특성을 인지할 수 있는 시스템 부재.
- **Action:** - K-Means 알고리즘을 활용하여 고객 특성에 맞춘 23개 군집 도출 (실루엣 스코어 최적화).
  - AWS Lambda와 Docker를 활용해 매월 1일 군집 모델이 자동 실행되도록 파이프라인 구축.
  - User 테이블에 결과를 적재하고, History 테이블을 만들어 유저별 군집 변화 트래킹.
- **Impact:** 직관에 의존하던 마케팅/현장 액션을 데이터 기반으로 전환하고, 현장 근무자가 고객의 특성을 즉각 인지할 수 있는 환경 제공.

### 3. 사내 데이터 리터러시 향상 및 Text-to-SQL 환경 구축 (Data Ops)
- **Background:** 사내 유일한 데이터 분석가로서 단순 쿼리 요청이 병목 현상을 일으켜 고도화된 분석 시간 부족.
- **Action:** - **SQL 스터디 주도 (4개월):** 회사 실제 데이터를 활용해 필수 필터링(status 등) 및 조인 방식 전수.
  - **확장성 있는 쿼리 제공:** 쿼리 전달 시, 조건(품목, 기간 등)만 수정하여 재사용할 수 있도록 주석 및 가이드 제공.
  - **데이터 명세서 및 Text-to-SQL:** RDB 관계도 및 유의사항을 명세화하고, Snowflake Intelligence에 Agent를 연동하여 자연어로 쿼리를 생성하는 환경 구축 (현재 사내 배포 테스트 중).
- **Impact:** 단순 데이터 요청 빈도 감소 및 "조건을 이렇게 바꾸면 되나요?"와 같이 구성원들의 주도적인 데이터 활용 문화 정착.

### 4. 사수 부재 상황에서의 인프라(Snowflake) 적재 장애 대응 및 안정화
- **Background:** DE/리더 부재 상황에서 K8s 인증서 만료 및 Airbyte 버전 충돌로 인한 전사 데이터 적재(Snowflake) 중단 사태 발생.
- **Action:** - K8s 로컬 클러스터 접근 불가 원인을 파악하고, Airbyte 재설치 및 환경 초기화 결단.
  - 기존 DAG 커넥션 정보가 유실된 상황에서, 데이터 용량(Raw count, Column 수)을 기준으로 부하를 균등 분할하여 DAG 재설계.
- **Impact:** 외부 지원 없이 신속하게 데이터를 복구하여 데이터 유실 방지. 단순 분석을 넘어 데이터 엔지니어링 파이프라인의 메커니즘을 내재화하는 계기 마련.
